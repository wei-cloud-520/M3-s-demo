# 世界观设定 — 《代码梦境》

## 核心设定
程序员发现自己写的每一行代码在被编译运行后，都会在某个他不认识的城市的某个人的梦里变成真实的场景。他不知道那个人是谁，但通过精心设计代码，他开始试图在对方的梦里传递信息。

## 主角
- **姓名**：陆辞（Lù Cí）
- **年龄**：28岁
- **职业**：后端开发工程师，在上海一家中型互联网公司工作
- **性格**：内向，习惯用逻辑解决一切问题，不善社交。下班后的生活几乎只有写代码和偶尔的深夜散步
- **动机**：发现"代码→梦境"的联系后，从好奇逐渐变成执念——他想找到那个做梦的人

## 关键规则
1. 代码必须被编译运行才能触发梦境效果
2. 梦境内容的清晰度与代码质量有关——写得好，梦境就越清晰；写得乱，梦境就模糊扭曲
3. 陆辞只能"设计"梦境场景，无法控制做梦者的行为和反应
4. 做梦者在梦里能看到代码中的文字（字符串、注释等），但陆辞只能通过这种方式单向传递信息
5. 陆辞无法确认对方是否真的收到了信息，直到某一天他发现了回应

## 风格定位
- 现实主义 + 微奇幻
- 文字克制，留白多，用技术细节制造真实感
- 情感线隐晦，通过梦境内容逐渐展开
- 节奏偏慢，适合睡前阅读
- 基调：孤独 → 好奇 → 执念 → 连接

## 技术细节（增加真实感）
- 陆辞主要用 Python 和 C
- 他发现 C 语言的内存操作能影响梦境中的物理规则
- Python 的随机数模块会让梦境出现不确定性
- 注释是传递文字信息的主要方式
- for 循环控制时间的流逝感
- 条件分支会在梦里创造岔路口
