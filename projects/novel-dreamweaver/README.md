# 《代码梦境》

> 一个人写的代码，在另一个人的梦里，变成了世界。

## 项目信息
- **题材**：现实主义 + 微奇幻
- **风格**：克制、留白、技术细节感
- **章节**：22章，每章 2000-3000 字
- **写作模型**：DeepSeek V4-Pro
- **当前进度**：设定完成 / 大纲完成 / 第一章待写

## 文件说明
- `setting.md` — 世界观、人物、规则设定
- `outline.md` — 完整章节大纲
- `chapters/` — 已完成的章节
- `drafts/` — 草稿

## 写作规范
1. 每章写作前读 setting.md + outline.md + 已有章节
2. 先生成本章详细节拍，确认后扩写
3. 代码片段必须真实可运行（或至少语法正确）
4. 技术术语不解释，用场景自然呈现
5. 情感通过细节传达，不直接抒情
6. 每章结尾留悬念但不刻意
