# 第一章：编译

凌晨一点二十三分，屏幕右下角的时间跳了一下。

陆辞揉了揉眼睛，指尖在键盘上停了两秒。办公室的空调出风口发出细微的嘶嘶声，日光灯管在头顶嗡嗡响。除了他工位上的显示器，整层楼都是暗的。

他在改一个后端服务的内存管理模块。线上环境偶尔会出现段错误，但复现不了，只能先做静态检查。陆辞切到终端，重新编译了一遍。gcc 的警告信息滚过屏幕，三行黄色的 unused variable 提示，没有错误。

他写了一段调试代码，在内存分配后打印偏移地址：

```c
void* ptr = malloc(BUFFER_SIZE + OFFSET);
#ifdef DEBUG_MODE
    fprintf(stderr, "[DEBUG] alloc offset: %p -> %p\n", 
            ptr, (char*)ptr + OFFSET);
#endif
    memset(ptr, 0, BUFFER_SIZE + OFFSET);
```

编译，运行。

日志正常输出。陆辞盯着终端里的地址值，准备切回代码继续改，手指已经放在了 Ctrl+S 上，但屏幕上又滚出一行：

```
[DEBUG] alloc offset: 0x7f8a4c0050e0 -> 0x7f8a4c0051a0
[DEBUG] secondary buffer: 0x7f8a4c005200
Segmentation fault (core dumped)
```

段错误。意料之中。但第三行后面跟着一串东西：

```
0x7f8a4c005200__0x6e694b0a
```

陆辞的动作停住了。

他盯着那串十六进制值。0x6e 0x69 0x4b 0x0a。ASCII。他在脑子里过了一遍——'n', 'i', 'K', '\n'。

"niK"。

换行符前面的三个字符。

他把日志往上滚，确认自己没有写过这行输出。fmt 字符串里只有两个 %p，不可能打印出第三段地址。而且那串十六进制不在任何缓冲区范围内——他刚才检查过所有指针的边界。

陆辞又运行了一遍。

同样的错误。同样位置。但这次后缀变了：0x6f48720a。'o', 'H', 'r', '\n'。

"oHr"。

他靠着椅背，手指无意识地敲了两下桌面。可能是栈被破坏了，随机数据。解释合理。但两个随机字符串拼起来——"niKoHr"——读着像某种拼音。他没有继续想下去，保存了日志文件，标记了 bug 位置，准备明天再查。

关电脑的时候，屏幕暗下去的瞬间，他在黑色反光里看到自己的脸。眼睛下面有青色的影子。

---

地铁已经停了。陆辞打了辆车回家。

后座的真皮座椅被上一个乘客坐得温热。车窗外面高架桥的路灯一盏一盏往后滑，间隔两秒。陆辞把额头抵在凉玻璃上，闭着眼睛但没有睡着。脑子还在转——那个段错误，那串十六进制，那个像拼音的字符串。

不是拼音。如果是拼音，"niK" 没有声调，"oHr" 也不对。可能是乱码。肯定是乱码。

司机放着一档深夜电台，女声在用气声唱一首粤语歌。陆辞听不清歌词，只能辨认出旋律的轮廓。窗外的城市在橙色光污染里模糊成一片。

到家的时候一点五十八分。他没洗澡，脱了外套直接倒在床上。枕头上有洗衣液的残留味道，某种合成花香。他在黑暗里睁着眼躺了大概三分钟，然后意识滑进了某个深处。

---

街角。

陆辞站在一个他不认识的地方。

路灯是暖黄色的，光打在潮湿的柏油路面上，反射出一片碎金。空气里有刚下过雨的气味——那种泥土和臭氧混合的清新感，真实到他能闻出层次。地上有一滩水渍，形状不规则，大概三十厘米宽。水面平静，倒映着路灯的光圈和三楼窗户里透出的蓝色荧光。

远处传来音乐声。不确定来源，像是某个开着的窗户里飘出来的，又像是从地下停车场入口的缝隙里渗上来的。旋律模糊，但节奏清晰，四四拍。

风吹过来。

他能感觉到风擦过皮肤的温度——凉的，大约十七八度的样子，带着一点湿气。衬衫袖口被吹得轻轻贴在手腕上。这触感太精确了。精确到他能分辨出风的方向：从左手边的巷子里吹过来，大约四到五米每秒。

街角有一棵银杏树。叶子还是绿的，没有黄。树干上贴着一张被雨水泡烂的传单，字迹已经模糊，只剩下一个二维码还能看清。路灯柱是深绿色的，油漆在离地一米二的位置有一块剥落，露出里面的铁锈。锈迹的形状像一个不规则的三角形。

他往前走了一步。鞋底踩在湿路面上，发出轻微的水声。真实。太真实了。

陆辞在梦里皱了皱眉。

他转过身，想看清街角转角处那栋楼的门牌号。数字是模糊的，但能看出是三个字——不是阿拉伯数字，是汉字。笔画依稀可辨，但怎么都读不出来。

然后他醒了。

---

窗帘缝里漏进来一道白光。手机屏幕显示七点四十二分。

陆辞躺在床上没动。天花板上有去年夏天蚊子血的痕迹，三小片褐色的点。他盯着那些点，脑子里全是刚才那个街角。

路灯的颜色。暖黄色。不是随便什么黄——是那种老式钠灯的色温，大约两千开尔文。他在梦里看到这个颜色的时候，脑子里甚至闪过了一个十六进制值：#F4A460。

水渍的位置。街角转角处偏左三十厘米。不规则的椭圆形。

风的温度。十七八度。

这些细节还在。通常梦醒了以后，细节会在几分钟内消散，像水渍蒸发。但这个梦没有。他闭上眼睛，还是能看到那个街角的每一个细节。树干上的传单。灯柱上的锈迹。远处音乐的四四拍。

陆辞坐起来，打开了笔记本电脑。

屏幕亮起来。他找到昨晚的代码文件，打开了调试日志。

光标停在那串十六进制值上。

0x7f8a4c005200__0x6e694b0a。

后面三个字节。0x6e, 0x69, 0x4b。他手写了一次 ASCII 转换——'n', 'i', 'K'。但第二次运行的结果不同，是 'o', 'H', 'r'。

不是固定的。

他开始往回翻更早的日志。前天的。大前天的。每个版本都有类似的尾随数据。之前他以为是段错误导致的栈垃圾，没在意。但现在他在意了。

前天：0x726157。'r', 'a', 'W'。大前天：0x4c6e49。'L', 'n', 'I'。

没有规律。

不对。

他重新排列顺序，按时间倒序读——

'L', 'n', 'I' → 'r', 'a', 'W' → 'n', 'i', 'K' → 'o', 'H', 'r'。

"L-n-I r-a-W n-i-K o-H-r"。

还是没规律。

他试着转成中文拼音的读法。"Lin" "raw" "nik" "ohr"——不对。

他试了另一个方向。不是 ASCII 字符，是十六进制值本身代表的东西。颜色值？内存地址？他在代码里写过一个颜色相关的常量吗？

陆辞打开设计师给的 UI 色板文件。

路灯的暖黄色，#F4A460。

他停住了。

梦里的那个路灯。色温两千开尔文，暖黄色，带一点点橙调。跟他梦里的颜色一模一样。但他在梦里看到路灯的时候，根本没有想起任何色值——那个认知是后来分析出来的，像一段被植入的记忆。

他往下翻代码。

水渍。梦里水渍在街角偏左三十厘米。他在内存管理模块里分配 buffer 的时候，用了起始地址加三十字节的偏移量。

```c
#define OFFSET 30  // bytes
```

风的方向。从左手边来。代码里的一个左值引用，lvalue。风速大约四到五米每秒。一个 for 循环的步进值是 4。

传单上的二维码。他在工程里引入了一个第三方库的校验码，32 位。

灯柱上铁锈剥落的三角形。代码里一个三元运算符：`(condition) ? a : b`。

梦里的每一个细节，都在代码里有对等物。

不是巧合。

陆辞的右手食指悬在触摸板上方，没有动。左胸口的位置有一种奇怪的感觉——不是紧张，不是害怕，更像是某行从未被执行过的代码突然在终端的某个角落打印出了正确结果。

他打开编辑器。

光标切到代码文件末尾。双斜杠。空格。

他打了一个问号。

删除。

又打了一个问号。

删除。

手指在键盘上停了三秒。

然后他打：

```c
// 你好吗？
```

保存。Ctrl+S。机械键盘的蓝轴发出清脆的咔嗒声。

终端里输入 make。回车。编译通过，没有警告。

./server --debug。

回车。

程序开始运行。日志一行一行向上滚。内存分配正常。请求处理正常。心跳检测正常。

没有多余的十六进制值。

他盯着终端看了大概一分钟。然后关掉了显示器，但没有关程序。

窗外开始有早高峰的车流声。陆辞靠着椅背，闭上了眼睛。

日光从窗帘缝隙里切进来，落在他闭着的眼皮上，一片暖红色。
