# 第一章：编译（GLM-5.1）

凌晨两点十七分。屏幕上的光标闪烁，频率稳定。

陆辞的手指悬在键盘上方，没有落下。终端里的日志滚动到最后一行，停住了。一个段错误。核心已转储。

他端起桌上的马克杯，咖啡已经凉透。抿了一口，放回杯垫时发出轻微的磕碰声。办公室只剩他一个人。头顶的日光灯管有一根坏了，另一根发出电流过境的嗡嗡声，像一只困在夏天的苍蝇。

他在调试一个内存分配的模块。

这不是他负责的项目，原本不需要他来处理。但下午的会议上，组长把这块烫手山芋推过来的时候，其他人都在低头看屏幕。他没学会拒绝，于是它就变成了他的。

程序的结构很简单。用链表存储一些城市建筑的元数据，然后递归遍历。问题出在某个指针上——释放了内存，但没置空。野指针。

他把椅子往后推了一点，揉了揉眼睛。隐形眼镜干得厉害，眨眼的时候上眼皮刮过眼球，有种砂纸磨木头的粗糙感。

窗外是上海深夜的写字楼群。大部分楼层已经暗了，零星亮着的灯光像棋盘上没收走的残子。远处高架上有车经过，尾灯拖出一条红色的线，然后消失在匝道拐角。

他重新开始看代码。

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    float x;
    float y;
    char name[64];
    int floors;
} Building;

typedef struct Node {
    Building* data;
    struct Node* next;
} Node;

typedef struct {
    Node* head;
    int count;
    char district[32];
} StreetCorner;
```

是他习惯的写法。结构体定义得规整，字段命名清楚。他在心里默念了一遍各个字段的含义，像检查清单一样逐项确认。

然后是初始化函数。

```c
StreetCorner* create_corner(const char* district) {
    StreetCorner* corner = (StreetCorner*)malloc(sizeof(StreetCorner));
    if (!corner) return NULL;
    
    corner->head = NULL;
    corner->count = 0;
    strncpy(corner->district, district, sizeof(corner->district) - 1);
    corner->district[sizeof(corner->district) - 1] = '\0';
    
    return corner;
}
```

这段没有问题。他往下翻。

添加建筑的函数：

```c
void add_building(StreetCorner* corner, float x, float y, 
                  const char* name, int floors) {
    if (!corner) return;
    
    Node* new_node = (Node*)malloc(sizeof(Node));
    new_node->data = (Building*)malloc(sizeof(Building));
    
    new_node->data->x = x;
    new_node->data->y = y;
    strncpy(new_node->data->name, name, sizeof(new_node->data->name) - 1);
    new_node->data->floors = floors;
    new_node->next = corner->head;
    corner->head = new_node;
    corner->count++;
}
```

他盯着这几行看了很久。逻辑是对的。头插法，新节点接在链表头部，count递增。

然后是遍历。

```c
void traverse_corner(StreetCorner* corner) {
    if (!corner) return;
    
    Node* current = corner->head;
    int i = 0;
    
    while (current != NULL) {
        printf("Building %d: %s\n", i, current->data->name);
        printf("  Position: (%.2f, %.2f)\n", 
               current->data->x, current->data->y);
        printf("  Floors: %d\n", current->data->floors);
        
        current = current->next;
        i++;
    }
}
```

也没问题。

最后是释放内存的函数。他找到了bug。

```c
void free_corner(StreetCorner* corner) {
    if (!corner) return;
    
    Node* current = corner->head;
    while (current != NULL) {
        free(current->data);
        free(current);
        current = current->next;  // 这里
    }
    
    free(corner);
}
```

"这里。"他轻声说。

先释放了节点，再试图访问`current->next`。`current`指向的内存已经被交还给了系统，再解引用它就是在读一块已经不属于他的地盘。有时候运气好，那块内存还没被覆盖，程序能正常跑完。运气不好，就崩。

段错误。核心已转储。

他修改了代码。

```c
void free_corner(StreetCorner* corner) {
    if (!corner) return;
    
    Node* current = corner->head;
    while (current != NULL) {
        Node* next = current->next;
        free(current->data);
        free(current);
        current = next;
    }
    
    free(corner);
}
```

用一个临时变量存住下一个节点的地址，然后再释放当前的。教科书级别的修改。

保存。编译。`gcc -g -o corner corner.c`。

没有警告。

他写了一个测试用的main函数，想要验证修复是否生效。但他没有用项目里的真实数据，而是在函数里硬编码了一个虚构的街角。

```c
int main() {
    StreetCorner* corner = create_corner("江宁路");
    
    add_building(corner, 0.0, 0.0, "便利店", 2);
    add_building(corner, 15.5, 0.0, "老式公寓", 6);
    add_building(corner, 0.0, 20.0, "咖啡馆", 3);
    add_building(corner, -10.0, 5.0, "书店", 4);
    
    /* 路灯在东北角 */
    /* 风从南边来 */
    
    traverse_corner(corner);
    free_corner(corner);
    
    return 0;
}
```

他犹豫了一下，加了那两行注释。没有原因，只是手指停在键盘上的时候，脑子里冒出了这两个画面。路灯在东北角。风从南边来。

运行。

终端输出了四个建筑的信息。程序正常退出，返回码0。

他关上笔记本的盖子。屏幕暗下去的一瞬间，办公室变得更暗了。那根日光灯管的嗡嗡声突然变得很响。

他收拾东西。双肩包，钥匙，手机。马克杯留在桌上，明天再洗。走廊的声控灯在他踩出第一步的时候亮起来，惨白的光打在防火门上。

电梯停在一楼。大堂的保安趴在前台，脸埋在臂弯里，睡着了。旋转门外，深夜的空气带着五月底特有的潮气，有下雨前泥土被挤压的味道。

他走向地铁站。末班车早就没了，但他想先走到那里，再决定是叫车还是继续走一段。街上偶尔有出租车经过，空车牌亮着橙色的灯。一辆外卖电动车从身边掠过，风声很尖，然后很快变小，消失。

他的脚步声在空旷的人行道上很清晰。一、二、一、二。右脚鞋底有一个地方磨薄了，踩下去的时候能感觉到地面的硬度通过那层橡胶传上来。

地铁站到了。入口的卷帘门拉下来一半，露出黑色的洞口。他没进去，在门口站了一会儿。

手机震了一下。公司的IM推送，有人在项目群里发了条消息。他没看，把手机放回口袋。

他叫了一辆车。

车来得很慢，他在路边等了八分钟。上车后司机问了一句"去哪"，他报了地址，然后两个人都没再说话。收音机开着，放的是深夜的情感热线。一个女人的声音在讲她丈夫经常很晚回家，主持人在安慰她。信号不太好，声音断断续续的。

他看着窗外。高架下面是一条河，河面上有路灯的倒影，被风吹得细碎，像一条解体的蛇。

到家的时候三点十一分。

他住在一个老小区的六楼。没有电梯。楼道里的声控灯坏了很久，他摸黑上楼，手扶着墙壁。墙面的涂料已经剥落了，指尖触到的是粗糙的水泥层和灰尘的颗粒。

打开门，没开灯。脱鞋，换拖鞋，把包放在门口的椅子上。空气里有洗洁精和泡面的混合气味，早上没洗的碗还泡在水槽里。

他走到卧室。床上的被子没叠，保持着他早上出门时的样子。他躺上去，没脱衣服，只是把鞋子踢掉了。一只鞋踢到了地板上，另一只还挂在脚后跟上。

天花板是白的。窗帘没拉紧，路灯的光从缝隙里渗进来，在靠近窗户的墙面上形成一条窄窄的橘色光带。

他闭上眼。

困意来得很慢。身体很累，但脑子还转着。那些代码在眼皮后面浮动——`malloc`、`free`、`struct`、`Node*`。他想让脑子停下来，于是试着数呼吸。一呼一吸，一呼一吸。到第十四次的时候，他失去了计数。

睡眠像一只手，从脚开始，慢慢地把他往里拉。

---

他站在一个十字路口。

路面是湿的。不是刚下过雨，是那种持续的、细密的潮湿，空气里悬浮着水汽，让远处的景物变得模糊。路灯的光在空气里散开，形成一个个光晕。

东北角有一盏路灯。

他看见了。灯柱是铸铁的，漆成黑色，底座有装饰性的花纹。灯罩是磨砂玻璃，里面透出来的光是暖黄色的，不是现在常见的LED白光。灯光照在地面上，形成一个不规则的圆。圆的边缘，柏油路面的纹理清晰可见——碎石、裂缝、一小摊积水。

他闻到了潮湿的沥青味。还有一点很远的地方飘来的烧烤的烟气。

风从南边来。

他不知道自己怎么知道南边在那里的。他就是知道。风带着温度和湿度的信息，贴过他的左脸，然后消失了。

他低头看自己的脚。穿着那双磨薄了底的鞋，站在路口的正中间。地面上有一条白色的停止线，褪色了，边缘被轮胎磨得模糊。他的脚尖刚好抵在线上。

四个方向。四条路。

右手边是一栋两层的建筑。招牌上写着"便利店"三个字，灯箱有一个角不亮了，"利"字的下半截淹没在黑暗里。透过玻璃门能看见里面的灯光——也是暖黄色的，和路灯一样。货架上东西不多，能分辨出矿泉水、方便面、几包颜色鲜艳的零食。收银台后面没有人。

左手边是一栋六层的老式公寓楼。外墙贴着白色瓷砖，有些地方已经脱落，露出底下的水泥和砖。一扇窗户亮着灯，在三楼。窗帘是碎花的，有一条缝没拉严。他看不清里面。

正前方偏左，稍微远一点的地方，有一栋三层的小楼。门口挂着一个木质的招牌，上面写着"咖啡馆"。门口有一个小小的雨棚，雨棚下面放着一块小黑板，用粉笔写着什么，但距离太远，看不清。门的右侧有一棵法国梧桐，树干很粗，表皮剥落，露出浅色的内皮。一根低矮的树枝上挂着一串灯泡，不亮。

偏后方，在他身后的方向，有一栋四层建筑。一楼有个门面，招牌写着"书店"，门关着。橱窗里摆着几本书，封面朝外。有一本蓝色的，有一本白色的。

他站在那里。

风又来了，这次带着更多的水分。他感觉有一滴微小的水珠落在了他的左手手背上。他低头看。没有水迹。但他能感觉到那个触感——凉的，圆的，极轻的。

这不像梦。

他以前也做过梦。正常的梦是模糊的，碎片的，逻辑跳跃的。你知道自己在公交车上，下一秒就变成了教室，再下一秒是一个你不认识的海滩。场景切换的时候没有过渡，你也不会觉得奇怪。

但这里没有切换。一切都连贯地、稳定地存在着。他转头的时候视野平滑地移动。便利店、公寓楼、咖啡馆、书店。路面、路灯、天空。天空是深灰色的，没有星星，没有月亮，但不是完全的黑。城市的光污染把云层照亮了，从底部，像一面脏脏的发光的天花板。

他试着走了几步。

脚踩在湿路面上，发出轻微的粘连声。鞋底和路面之间有一层水膜，每一步都有细微的分离感。

他走到便利店门口。玻璃门上映出他的模糊影子。他伸手推门。

门没锁。

推开的瞬间，便利店的气味涌出来。冷气、塑料包装袋、关东煮的汤底、一点点消毒水。门口的地垫是灰色的，踩上去比外面软。收银台上有一台电脑屏幕，亮着，显示的是一个他看不清的界面。

他走到货架前。矿泉水的品牌他不认识。标签上的字他能看清楚——"云山泉"，蓝色的字体，背景是一座水墨风格的山。方便面也是他不熟悉的牌子。零食的包装上印着外文，不是英文，他分辨不出是哪种语言。

他拿起一瓶矿泉水。塑料瓶身有点凉。他拧开盖子，喝了一口。

有味道。是矿泉水的味道。微量的矿物质在舌尖上留下一点干涩的感觉。

他咽下去。

这不对。

他放下瓶子。瓶子里剩下的水晃动，发出他能听见的声音。

他走向门口。推开门的时候，外面的空气重新包裹了他。潮湿的、带沥青味的空气。

他抬头看那盏路灯。东北角。

路灯在晃。

不是风。或者说，是风，但不是他能感受到的风。灯柱很稳，但灯罩在轻微地摆动，像有什么东西在很高很远的地方经过，带起了气流。

他注意到路灯的光在变化。不是亮度，是颜色。暖黄色在一点一点地偏移，向冷白的方向。很慢。他盯了一会儿，确认了。色温在变。

然后他听到了声音。

很远的地方，像隔着几条街。一个低频的嗡嗡声，持续的，没有旋律。像一台很大的机器在运转。像电流通过变压器。

像日光灯管。

他醒了。

---

天花板是白的。窗帘缝隙里的光是灰蓝色的，天快亮了。

他躺在床上一动不动。

手背上还能感觉到那一滴水。手背上的皮肤记住了那个触感——凉的，圆的，极轻的。

他翻身拿起手机。五点五十八分。

他盯着屏幕上的数字。六点整的时候，手机震了一下，一条推送。他没有看。

他坐起来。脚碰到地板的时候，他低头看了一眼。拖鞋在床边。他穿上拖鞋，走到书桌前。笔记本电脑还在包里。他拿出来，打开。

屏幕亮起来的时候，眼睛有一瞬间的刺痛。他眯着眼等了几秒，然后输入密码。

桌面。他找到那个文件。`corner.c`。

双击打开。代码出现在编辑器里，字体是他设置的等宽字体，白底黑字。

```c
int main() {
    StreetCorner* corner = create_corner("江宁路");
    
    add_building(corner, 0.0, 0.0, "便利店", 2);
    add_building(corner, 15.5, 0.0, "老式公寓", 6);
    add_building(corner, 0.0, 20.0, "咖啡馆", 3);
    add_building(corner, -10.0, 5.0, "书店", 4);
    
    /* 路灯在东北角 */
    /* 风从南边来 */
    
    traverse_corner(corner);
    free_corner(corner);
    
    return 0;
}
```

他看着那几行。

`add_building(corner, 0.0, 0.0, "便利店", 2);`

两层的建筑。便利店里，灯箱有一个角不亮了。

`add_building(corner, 15.5, 0.0, "老式公寓", 6);`

六层的老式公寓楼。外墙贴着白色瓷砖，有些地方脱落了。

`add_building(corner, 0.0, 20.0, "咖啡馆", 3);`

三层的小楼，门口有法国梧桐。

`add_building(corner, -10.0, 5.0, "书店", 4);`

四层建筑，一楼是书店。

`/* 路灯在东北角 */`

东北角有路灯。

`/* 风从南边来 */`

风从南边来。

他往后靠在椅背上。椅子发出轻微的吱呀声。

窗外有鸟开始叫了。一开始只是一两声，断续的，像在试探。然后更多的声音加入，变成一片杂乱的、没有旋律的合唱。

他重新看代码。

建筑的位置坐标。便利店的`(0.0, 0.0)`是原点，他站的位置。老式公寓的`(15.5, 0.0)`在右边。咖啡馆的`(0.0, 20.0)`在前面。书店的`(-10.0, 5.0)`在左后方。

他闭上眼。梦里的画面还在。右手边是便利店。左手边是公寓楼。正前方是咖啡馆。偏后方是书店。

他对了一遍。

右边。正x轴方向。`15.5, 0.0`。

前面。正y轴方向。`0.0, 20.0`。

左后方。负x，正y。`-10.0, 5.0`。

全部吻合。

他睁开眼。

他的手放在键盘上，但没有动。屏幕上的光标还在闪烁，和昨晚离开公司时一样的频率。

巧合。

他在脑子里过了一遍这个词。 coincidence。概率论里的随机事件。大数定律下，任何看似不可能的事情都有可能发生。一百只猴子在打字机前敲一百年，总能敲出一句莎士比亚。

他写了一段简单的测试代码，在凌晨三点运行。然后做了一个梦。梦里的场景刚好和代码里的数据对应。

只是巧合。

他关上电脑。站起来走到窗前，拉开窗帘。

天已经亮了。太阳还没出来，但天空的底部有一条橙色的光带。楼下的小区花园里，有一个老人在打太极。动作很慢，像一套被时间拉长的程序。

他看了很久。

然后他去卫生间洗了把脸。水很凉，和梦里那滴落在手背上的水珠一样的温度。他关上水龙头，看着镜子里的自己。眼睛里有血丝，眼袋有点深。二十八岁的人，看起来像三十二。

他走回书桌前，又打开了电脑。

他新建了一个文件，名字叫`test_dream.c`。

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    /* 今天是周三 */
    /* 气温二十六度 */
    /* 云层很厚 */
    
    printf("If you can see this, wake up.\n");
    
    return 0;
}
```

他编译运行。终端输出了那行英文。程序退出。

他关上电脑，穿上外套。

出门前他看了一眼时间。六点四十二分。

今天可以晚点到公司。他有这样的权限——把加班的时间换算成调休。组长不在乎他什么时候来，只要代码能按时提交。

他下了楼。走出小区大门。街上的人开始多起来了，早餐铺的蒸笼冒着白气，有包子的味道。他没有停下来买，继续走。

他走到了一个十字路口。

不是梦里的那个路口。这个他认识，是公司附近江宁路和昌平路的交叉口。但他还是站在路口中间，抬头看了一眼东北角。

没有铸铁路灯。只有一根水泥电线杆，上面贴着一张撕了一半的小广告。

红灯亮了。他站在停止线后面等。

绿灯亮的时候，他过了马路。走了几步，他停下来，回头看了一眼那个路口。

便利店的灯箱全亮着。公寓楼外墙干干净净。没有法国梧桐。

他继续走。

手指在口袋里碰到了手机。他拿出来，打开备忘录，在空白页面上打了一行字：

"梦里是什么城市？"

他看着这行字看了几秒，然后删掉了。

手机放回口袋。

他走进公司楼下那家真正的便利店，买了一杯美式和两个饭团。收银台后面的小姑娘在玩手机，收了钱，找了他的零钱。硬币放在手心里是温的。

他走出便利店。

太阳出来了。
